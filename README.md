# Vorazis
Html Romerito


Projeto de autoria Web:
 Relatório do Trabalho Desenvolvimento de um site sobre o universo literário de Jogos Vorazes.

Aluno(a): Sofia Marques, Danielly Evelyn, Maria Clara e Tiago Cirilo. 
Professor(a): Romerito Instituição: IFRN Ano: 2026

Introdução:
 O presente trabalho consiste no desenvolvimento de um site temático inspirado na série de livros Jogos Vorazes, escrita pela autora Suzanne Collins. A proposta foi criar uma página interativa e organizada, na qual os visitantes pudessem conhecer os principais livros da franquia e acessar páginas com informações sobre cada obra. O projeto utiliza uma identidade visual inspirada no universo de Panem, com cores escuras, detalhes dourados e elementos relacionados ao fogo e à resistência.

Objetivo geral: Desenvolver um site utilizando HTML e CSS, aplicando conceitos de estruturação de páginas, estilização e organização de elementos com Flexbox.

Objetivos específicos:  
Criar uma página inicial de boas-vindas ao usuário; Apresentar os livros disponíveis para consulta, Desenvolver páginas individuais com informações sobre as obras. • Utilizar links para facilitar a navegação entre as páginas. • Aplicar cores, fontes e elementos visuais relacionados ao tema escolhido.

Tecnologias utilizadas: HTML5 Utilizado para construir a estrutura das páginas, inserir textos, títulos, imagens, links e conteúdos.

CSS3 Utilizado para definir cores, fontes, tamanhos, espaçamentos, bordas, animações e aparência do site.

Flexbox Utilizado para organizar os elementos da página, distribuir os cartões dos livros e adaptar o layout.

Desenvolvimento do Projeto:
 O desenvolvimento foi dividido em etapas para facilitar a construção e a organização do site.

01 - Criação da página inicial Foi desenvolvida uma página de boas-vindas com apresentação do tema, avatar de personagem e opções de livros.

02 - Organização dos livros Foram criados cartões para apresentar as quatro obras e permitir que o usuário escolha qual deseja conhecer.

03 - Criação das páginas internas Foram planejadas páginas individuais para apresentar sinopses, personagens e informações sobre os livros.

04 - Estilização com CSS Foram aplicadas cores, fontes e propriedades Flexbox para criar uma identidade visual consistente.

05 - Conexão entre as páginas:
 Foram utilizados links HTML com href para permitir a navegação entre a página inicial e as páginas dos livros.

Conteúdos apresentados:
 O site apresenta quatro livros do universo Jogos Vorazes:

Jogos Vorazes Publicado em 2008. Apresenta a história de Katniss Everdeen e sua participação nos Jogos.

Em Chamas Publicado em 2009. Mostra o crescimento da revolta contra a Capital.

A Esperança Publicado em 2010. Acompanha Katniss durante a revolução de Panem.

A Cantiga dos Pássaros e das Serpentes, Publicado em 2020. Apresenta a juventude de Coriolanus Snow durante a décima edição dos Jogos.

Aprendizados:
 Durante o desenvolvimento do projeto, foram trabalhados conceitos importantes de programação para a web, como a criação de estruturas HTML, a utilização de CSS externo e a organização dos elementos com Flexbox. Também foi possível compreender melhor como funcionam os links entre diferentes páginas, a organização de arquivos em pastas e a criação de layouts que se adaptam a diferentes tamanhos de tela.

Conclusão:
 Conclui-se que o desenvolvimento do site possibilitou colocar em prática os conhecimentos adquiridos sobre HTML e CSS. A criação de um projeto temático tornou a atividade mais criativa e permitiu explorar diferentes recursos de estruturação e estilização. Além disso, o projeto contribuiu para o aprendizado sobre organização de arquivos, navegação entre páginas e construção de interfaces para usuários.
